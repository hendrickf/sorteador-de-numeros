Como functiona o sorteador de números?

O sorteador utiliza um algoritmo de geração aleatória para criar números dentro do intervalo específico pelo usuário.

Posso escolher o intervalo dos números?

Sim, você pode definir os valores mínimo para o intervalo dos números sorteados.
